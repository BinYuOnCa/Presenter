# Presenter — 投影屏定时：时钟 → 倒计时 → 当天 PDF

内建屏放 OBS，外接投影屏由 Presenter 自动接管：

| 时间 | 投影屏显示 |
|---|---|
| 10:25:00 | 全屏：当前时间（带秒）+ 固定文字和背景图 |
| 10:28:30 | 其他不变，时间变成 90 秒倒计时（1:30 → 0:01） |
| 10:30:00 | 全屏显示 `pdf/yyyymmdd.pdf`（如 `20261025.pdf`）第 1 页 |

翻页用全局快捷键，焦点留在 OBS 也照样有效。投影窗口不会抢焦点，鼠标点击也会穿透。

---

## 一、第一次准备（约 10 分钟）

1. **把解压出来的 `Presenter` 文件夹放到主目录**，即 `~/Presenter`。在“下载”里解压的话，终端运行：
   ```bash
   mv ~/Downloads/Presenter ~/
   ```
   放在主目录（而不是“下载”“桌面”“文稿”）可以避免 macOS 的文件访问权限弹窗。

2. **编译**。打开“终端”，运行：
   ```bash
   cd ~/Presenter
   bash build.sh
   ```
   如果提示没有编译器，先运行 `xcode-select --install`，装完（5–15 分钟）再运行 `bash build.sh`。
   装过 Homebrew 的电脑一般已经有了。成功后文件夹里会出现 `Presenter.app`。

3. **显示器设置**：系统设置 → 显示器，投影仪设为 **扩展显示器**（不要“镜像”）。
   建议把内建屏设为主显示器（菜单栏在内建屏），这样通知横幅不会弹在投影上。

## 二、每次使用

1. 把当天的 PDF 改名为日期（例如 `20261025.pdf`），放进 `~/Presenter/pdf/`。
2. **10:25 之前**双击 `Presenter.app`。屏幕上不会立即出现窗口，菜单栏会出现 `⏱10:25:00`。
3. 之后全部自动。菜单栏图标会随时显示状态：`🕐时钟` → `⏳1:23` → `📄3/12`（第 3 页 / 共 12 页）。
4. 结束后在菜单栏图标里选“退出”，或按 `⌃⌥Esc`。

（菜单栏图标太多时，刘海屏可能把它挡住；所有关键操作也都能用下面的快捷键完成。）

菜单栏标题前出现 **⚠️** 表示有问题（没找到今天的 PDF、没检测到投影屏、快捷键冲突），点开菜单可看到具体原因。

## 三、快捷键（全局，焦点在哪个程序都有效）

| 动作 | 默认快捷键 |
|---|---|
| 下一页 | `⌃⌥→` 或 `⌃⌥↓`（Control + Option + 方向键） |
| 上一页 | `⌃⌥←` 或 `⌃⌥↑` |
| 回到第一页 | `⌃⌥1` |
| 黑屏开/关 | `⌃⌥B` |
| 立即显示 PDF（跳过倒计时） | `⌃⌥P` |
| 退出 Presenter | `⌃⌥Esc` |

另外，菜单栏里还可以：立即显示时钟、立即开始倒计时、恢复按时间表自动、重新载入 PDF。

**和 OBS 不冲突的保证：**
- 启动时程序会读取 OBS 的快捷键设置（`~/Library/Application Support/obs-studio`），与 OBS 相同的组合**不会启用**，菜单栏会标 ⚠️ 提示你换一个。
  菜单 → 快捷键 里会显示“已读取 N 个绑定”；如果你在 OBS 里设过快捷键而这里显示 0，说明没读到，请按下面人工核对。
- 被其他软件占用的组合（例如 Rectangle、Magnet 等窗口管理工具常用 `⌃⌥←/→`）也会被检测出来并标 ⚠️。
- 建议仍人工看一眼：OBS → 设置 → 快捷键，确认没有用到上表的组合。

**改快捷键**：编辑 `config.json` 里的 `hotkeys`，保存后退出并重新打开 Presenter。写法如 `"ctrl+alt+right"`、`"ctrl+cmd+n"`。
用翻页笔（多数发送 PageDown/PageUp）：在 `next` 里加 `"pagedown"`，`prev` 里加 `"pageup"`。
注意：macOS 15 起不允许只用 Option（⌥）或 Option+Shift 的全局快捷键，组合里请带上 ctrl 或 cmd。

## 四、彩排（强烈建议正式用之前做一次）

先退出正在运行的 Presenter，然后在终端运行：

```bash
cd ~/Presenter
open Presenter.app --args --test --countdown 10
```

测试模式：马上显示时钟，8 秒后开始 10 秒倒计时，然后显示 PDF。
如果 `pdf/` 里还没有今天的 PDF，会用 `pdf/sample.pdf`（示例文件，正式模式不会用它）。
没接投影仪时，会在当前屏幕中间开一个小窗预览。

其他测试参数：
- `--countdown 90`：测试完整的 90 秒倒计时
- `--lead 30`：时钟显示 30 秒后才开始倒计时
- `--pdf 某个文件.pdf`：指定 PDF
- `--date 20261101`：按某天的日期找 PDF

想看实时日志，可以直接运行：`./Presenter.app/Contents/MacOS/Presenter --test`（按 Ctrl+C 结束）。

## 五、修改内容

- **文字**：编辑 `stage.html`，改标了 ✏️ 的几行（标题、副标题、底部文字）。用浏览器直接打开 `stage.html` 就能预览；
  预览倒计时：在地址后面加 `?mode=countdown&s=90`。
- **背景图**：替换 `images/background.jpg`（建议 1920×1080）。
- **徽标**：放一个 `images/logo.png`，自动显示在标题上方；没有就不显示。
- **颜色/字号/倒计时格式**：`stage.html` 顶部的 🎨 和 ⚙️ 部分（倒计时可选 `1:30`、`01:30` 或 `90`）。
- **时间、PDF 文件夹、文件名格式**：`config.json`（例如 PDF 放桌面就写 `"pdfFolder": "~/Desktop"`）。

改 `stage.html` / 图片 / `config.json` 都不用重新编译，重新打开 Presenter 即可。

## 六、可选：每周自动打开

```bash
bash autostart.sh on              # 每周日 10:10 自动打开 Presenter
bash autostart.sh on 09:50 sun    # 自定时间/星期（daily = 每天）
bash autostart.sh off             # 取消
```
Mac 需要开机且已登录。

## 七、注意事项与容错

- **不要合上笔记本盖子**（内建屏要显示 OBS）。程序运行期间会阻止系统休眠、显示器休眠和屏保。
- 建议开启“勿扰模式”，避免通知弹出。
- **晚开也没关系**：10:27 打开 → 直接显示时钟；10:29 打开 → 显示剩余倒计时；10:35 打开 → 直接显示 PDF 第 1 页。
- **PDF 临时补上也行**：10:30 时找不到 PDF，会先继续显示时钟，每 2 秒重试，文件一放进去就自动显示。倒计时开始后才替换了 PDF 也没问题，10:30 会载入最新的版本。
- **投影线松了**：窗口自动隐藏（不会跑到内建屏挡住 OBS），重新接上自动恢复。
- 投影显示的内容如需进直播，在 OBS 里用“显示器采集”选投影屏即可。
- 出问题时看菜单里的“查看日志”（`presenter.log`）。

## 文件说明

| 文件 | 作用 |
|---|---|
| `presenter.swift` | 程序源代码 |
| `build.sh` | 编译成 `Presenter.app` |
| `config.json` | 时间、PDF 位置、快捷键 |
| `stage.html` | 时钟/倒计时画面（文字、样式） |
| `images/` | 背景图、徽标 |
| `pdf/` | 每次的 PDF（`sample.pdf` 仅供测试） |
| `autostart.sh` | 可选：每周定时自动打开 |
